# Start here and focused demos

RC2's Start here notes include the grouped controller workflow. The optional
RC2 profiles are separate imports. Use a disposable test, explicitly enable
inputs, review picture/sound, save a checked reference and retain a fallback.

Open **Files > Sample scripts > Start here: Sightline feature tour**.
The same `welcome.md` opens automatically on a fresh profile with no scripts.
It is a guided sample with fourteen stops, rather than a production recording.
It works in Scroll mode without enabling a camera, microphone, AI or recorder.

The tour covers transparency over slides/calls/camera previews; Scroll, Voice
and Notes; four independent text types and saved reading themes; reading aids,
mirroring and the section pill; preparation, local position feedback, test
playback and saved references; scripts/slots; cues and commands; Connections,
Stream Deck and other controllers; OBS state and modes; local MCP grants; and
retakes and edit-pack handover. Pause at a stop to try its suggested action.

Samples open read-only. Use **Save a copy** before personalising a script.
Opening them does not enable integrations or run a recording command.
Long setup/command instructions use paused-only production comments. Inline
brackets hold brief delivery cues. Read the ordinary text; use a command
example deliberately, rather than narrating it.

For any recording, confirm its real state before making a clap or slate.
Connectivity, test playback and camera lip sync are separate checks. Quiet
audio advice does not require blindly increasing gain and room noise.
Retain original media with the matching edit pack. Live word/caption timings
and unmatched-word flags need review against recorded-audio transcription.

The focused recording demos contain no executable `{record: …}` actions by
default. Their optional exercises require OBS recording permission. Continuous
and linked modes behave differently at a prompting pause; test the selected
mode before production. `stop` pauses prompting; explicit `finish` / `end`
finishes OBS with permission. `restart section` retakes this section;
`restart` alone resets the script.


RC1 adds two final stops for post-record review and the cancelable Settings tour.
Use [post-record setup](guide/19-post-record-review.md) for local runtime/import
instructions. A tour never starts a device or applies preferences.
