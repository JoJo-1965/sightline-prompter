# Preview 05 numeric patch

Unpublished Windows patch, documentation revision 5. The approved layout and
recording workflow are retained. Launch from
`D:\Sightline\Dev\Builds\Previews\settings-layout-preview-05-numeric`.

- Text size, line spacing, voice response and WPM use increments of five.
- Margins, opacity, countdown and reading positions use whole values.
- Fine head alignment and toolbar readouts show at most two decimal places.
- Sliders and number boxes share values and increments. Typing, dragging and
  keyboard adjustment follow the same rules.
- Displaying a rounded control does not rewrite an existing precise setting;
  adjusting it commits the chosen step.

The launcher reuses the current Preview 05 profile, including the promo slot,
microphone, OBS and Stream Deck pairing. Close the previous preview normally
after saving any draft. Do not restart during a take. Follow the existing
[promo recording preparation](PREVIEW-05.md).
