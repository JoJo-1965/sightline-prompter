# Settings Preview 07

Unpublished combined preview, 2 November 2026. App 1.1.0, documentation revision
8, companion Stream Deck 0.2.0. Includes all [Preview 06 fixes](PREVIEW-06.md)
and the full queued request for smaller mirror buttons. Both axes reuse the
main toolbar artwork; their compact buttons retain standard control height.
There are no new functions, permissions or scripting changes.

The approved navigation, Prompter layout name, visible button subtabs,
mode-aware controls, guide references, spacing, help, focus cues and non-modal
example remain included. The source native check passed at five sizes after
the button correction. The new executable receives the same packaged check
before handover. Hardware recording and sync acceptance remain separate.

Run **Launch Settings Preview 07.cmd** from the preview folder. It reuses
`settings-layout-preview-05/test-profile`, retaining settings, pairing and promo
slot 4. The installed release has a separate profile. A pre-launch state backup
is retained before switching. No recording starts during the handover.

Help, gallery, feature-grid exports and the JL draft accompany this preview.
No release, tag, Marketplace change or live website deployment is included.
