# RC3 promo: pointing and graphic directions

Use with `PROMO-SCRIPT-1.3.0-RC3.md`. This is a new rehearsal draft requiring
wording/direction review before recording. It does not change the captured
Slot 4 script or prove that a gesture exists in earlier footage.
The machine-readable plan is `PROMO-POINTING-DIRECTIONS-RC3.json`.

Only these moments need gestures. Let the gesture complete, return naturally
to the lens and keep delivery conversational. The inline `[point …: label]`
cue is silent. Its longer `<!-- GRAPHIC label. … -->` note is for preparation
and editing, so the screen does not fill with production instructions.

## Authoring and recording

Keep the label, direction and spoken anchor in this plan, its JSON and the
script in step when wording changes. Read the
[shared authoring contract](../POINTING-CUE-AUTHORING.md). Use Normal or Dimmed
Inline directions. Complete framing, sound and test checks, then confirm the
recorder is recording before a slate/clap. Export the matching script snapshot,
take log, cue files and scratch audio with the original master recordings.

## Production

Resolve the asset status in the JSON before editing: labels identify intent,
not attached files. Use current legible UI captures and consistent 16:9 frames;
keep Joanne's face and caption area clear. Preserve the prompter translucency
when showing it over content. Reuse actual Stream Deck icons.

Use the captured script ID, section, selected take and nearby words in
`production-cues.json`, then verify the visible gesture. Check the actual
recording orientation: an unmirrored shot places presenter-left on viewer-right.
Preview mirroring alone does not determine placement. Spoken timing is only
a navigation candidate; missing timing is unavailable, not zero. Apply the
correct measured file offset, then adjust the graphic to the performance.

Flag a missing gesture, asset or mismatched take rather than inventing evidence.
Existing Slot 4 footage keeps its original script; these new gestures require
a new performance/pickup if they are to appear in that video. No rendered edit
or automatic graphic insertion is promised by this direction plan.
