# RC14 combined controller and AI UAT

Use the supplied launcher and a retained copy of your latest RC13 profile.
All occupied slots, active script, appearance and mappings must match.

1. In Stream Deck, confirm existing buttons/dials still work and your edited
   profile is still selected. Choose Display > Clean view on a disposable key;
   check its icon/state, press again to restore. Repeat with On top. Existing
   HUD and click-through choices remain. Reading mode switches while paused.
2. In the operator window, try Voice/Page/Scroll and the three display toggles.
   Confirm the main toolbar and remote show the same state after switching.
3. Optionally select Connections > Pad and phone > Call overlay. This replaces
   that selection only when you choose Use preset; keep a note of any custom
   layout first. Existing mappings can assign the same actions. Stream Deck's
   separate Call Overlay RC14 files are optional imports, not replacements.
4. Check the refreshed AI kit. Reconnect an MCP client; expect eight tools.
   With read-only grants, status works and writes fail. Enable prompting/control
   permission, set clean-view on then off with sightline_view and select a
   paused mode with sightline_prompt. Keep the recording grant off for this
   exercise: display/mode changes must work without starting capture/recording.
5. Confirm Ctrl+Shift+X recovery, the top-edge Show controls tab and existing
   keyboard shortcuts. Active delivery/editing must block mode changes.

Automated tests cover eight MCP tools and grants/revocation, real operator IPC,
native pin/clean recovery, pad state and no media/recorder side effects. Plugin
tests cover 174 legacy key and 22 dial cases, old archive hashes, generated
profile grids, runtime guards and the 25 optional call imports. Physical
hardware/microphone and multi-monitor acceptance remain operator checks.
