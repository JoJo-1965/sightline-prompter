## Five-minute check

1. Start with the supplied launcher. Your RC12 settings, active slot and all
   nine occupied slots should be retained. Do not overwrite your promo script.
2. Open an editable scratch document with Ctrl+E. Paste plain text, choose
   Auto format, review options and preview, Cancel once, then Apply. Check that
   words/punctuation stay intact. Undo, apply again and Save. Try selected text.
3. Use Insert to add a short cue, heading, production note and app code at the
   cursor. Edit selected values, Undo/Save. Insertion must not run the code.
4. While paused, choose Page and use Previous/Next; check both disabled ends.
   Try Voice and Scroll. Voice still needs enabled speech/microphone. Held Voice
   may switch modes; switching must not start or pause OBS recording.
5. With a call or slide behind, try On top and Click-through. Script clicks
   should reach the app behind; Sightline controls should still accept clicks.
   Choose Clean view, then hover the top-edge tab and select Show controls.
   Check Escape while Sightline is focused and global Ctrl+Shift+X recovery.
6. Check compact/wide toolbars: Help, Settings and window controls stay upper
   right. Test a paused quick edit and Voice resume. Existing settings layout,
   appearance and guide reference should be retained.
7. If using OBS, explicitly allow recording controls, confirm the connection,
   choose Record take and verify red RECORDING plus prompting. Finish explicitly.
   A sync cue must land after recording starts. Continue the RC12 microphone,
   dialog and multi-monitor checks on your actual hardware.

## Evidence and limits

Source checks cover unchanged words/order, insertion/format preview/Cancel/
Undo/Save, canonical codes, shared modes, native click-through and clean-guide
recovery, responsive toolbars and Voice boundary/Retake regression. Packaged
checks repeat authoring/overlay and insertion flows against the built executable.
Synthetic audio/OBS is used for automated checks; physical hardware UAT remains.
Live word timings are navigation estimates; use recorded transcription for cuts.
