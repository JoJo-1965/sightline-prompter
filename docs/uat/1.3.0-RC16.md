# RC16 toolbar/session-row check

RC16 includes RC15 with a toolbar-layout correction. Use the supplied launcher
and copied saved profile; occupied slots, active script, fonts and mappings stay.
The existing production recording remains evidence. This short check covers
the newer layout; a complete new performance is not required.

1. On the small prompter screen, reveal the toolbar. Section and OBS controls
   should sit below all toolbar rows. Move the pointer down into the script:
   the toolbar hides and the session row moves near the top of the window.
2. Move onto Record take or Finish recording without clicking. The pointer
   should remain visible and the buttons should stay in place. Move into the
   clear top edge to reveal the toolbar again. The script must not jump.
3. Resize with the toolbar hidden, then reveal it. Check opening comments can
   still scroll above the reading line without being covered. Repeat with the
   toolbar pinned and while making a paused quick edit.
4. Clean view hides the entire session row. Show controls or Escape restores
   it. Existing OBS permissions and recording actions retain their behaviour.

Native regression uses disposable profiles and no camera, microphone or OBS.
It covers 1440, 1024, 760 and 560-pixel widths, real pointer events, hidden
resize, review clearance, quick edit, pin and Clean view. RC15's recording/setup
checks remain available in [the previous checklist](1.3.0-RC15.md).
