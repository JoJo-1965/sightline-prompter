# Sightline 1.2.0 RC 2 · demo refresh

Source: `33ad364`; documentation revision 12; companion 0.2.0.
RC 2 carries the RC 1 app features and refreshes the demo library as one batch.

- The first-run tour has twelve practical stops covering core and new features.
- All twelve sample files are reviewed; Framing, audio and reference is now
  available in Files > Sample scripts.
- Long setup, camera and command exercises use production comments. Short
  delivery cues remain inline. Command examples are excluded from spoken copy.
- Recording demos preserve Ideal, confirm recording before sync, distinguish
  connection from media review, and qualify live timing/coverage estimates.
- Spoken targets are recalculated; Notes uses real talking points with ad-lib
  time. The continuous example has a realistic whole-script target.
- The AI authoring brief, directive guidance and installed AI kit match these
  practices. The formatting diagnostic retains exactly one deliberate bad tag.

Checks before packaging: all delivery demos pass the script checker; the
formatting fixture reports only its intended unknown tag. The unit suite passes.
Packaged first-run/rendering and installer checks follow before handover.

For an existing profile, choose **Files > Sample scripts > Start here: Sightline
feature tour** to open this copy. A profile without scripts opens it automatically.
Samples stay read-only; Save a copy to customise them. Current personal scripts,
slot assignments and recording media are not replaced by the update.
