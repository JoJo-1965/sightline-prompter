# Settings Preview 06

Unpublished review build, 2 November 2026. App version 1.1.0, documentation
revision 7, companion Stream Deck 0.2.0. This is the combined approved batch.

The queue review includes the four visible chat cards: clearer Prompter layout
naming, visible group subtabs, the toolbar's mirror icons and one combined
preview incorporating all previous UI fixes. The approved navigation, centre
controls and right example remain the layout basis. Screens, Reading aids,
Head guide and Installed components use visible button subtabs. Mode and pace
offers Notes / page, Voice and Scroll with relevant controls only.

Head guide includes placement, appearance and a recording reference with
restore, separate from Ideal. Eye-line configuration follows its enable switch.
Focus strength follows Focus band; reading aids have contextual help. Numeric
steps and display precision remain bounded. Mirror spacing and inset focus cues
are consistent. Narrow windows use a separate non-modal example with a standard
Close button; wide windows keep the third column. Persistent Guide and OBS
actions wrap rather than overlap, including with the capture warning visible.

Use **Launch Settings Preview 06.cmd** in the preview folder. It reuses
`settings-layout-preview-05/test-profile`, retaining slot 4 and the existing
microphone, recording and pairing preferences. Back up that profile before
first launch. The installed release uses a separate profile.

Native checks cover all 34 sections, every subtab, five Settings sizes, saved
mode/guide state, Apply/Cancel, theme files, pointer interaction and preview
closing. Recorder/head-guide fixtures cover confirmed recording transitions.
These fixtures do not certify physical controllers, a real camera recording,
capture exclusion, microphone quality or audiovisual synchronization. Complete
the [recording acceptance checks](guide/14-acceptance-test.md) before relying
on a production recording. No recording starts merely by loading the script.

Help, guide, gallery, feature matrix and JL review snapshot are maintained
together. No release tag, Marketplace submission or live site deployment is
part of this preview handover.
