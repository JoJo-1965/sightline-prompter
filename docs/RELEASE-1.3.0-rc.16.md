# Sightline 1.3.0 RC16

## RC16 — Session controls follow toolbar visibility

15 November 2026 · documentation revision 32. Includes RC15.

- The section pill, recorder controls and other session indicators dock near
  the top edge when the main toolbar hides. Revealing the toolbar places the
  row below its full height, including wrapped compact layouts.
- Moving onto a persistent recorder button keeps it in place and shows the
  pointer. Move to the clear top edge to reveal the main toolbar.
- Toolbar hiding/reveal preserves the script position. Opening review notes
  retain clearance after resizing with the toolbar hidden. Pinned controls,
  paused quick editing and Clean view keep their existing behaviour.

This is a layout correction. Settings, scripts, slots, recorder behaviour,
controller profiles, MCP tools and approved pointing-target geometry retain
their meaning. The previous frozen RC15 remains available.
