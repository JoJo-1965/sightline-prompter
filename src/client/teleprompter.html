Sightline Prompter

Adapted and enhanced by Joanne Lockwood from SEE Change Happen Ltd. It adds:

  • Built for AI: an AI script prompt and a script checker
  • A local API for AI agents, and a take log for the edit
  • Steady scrolling, a countdown, and a progress bar
  • A control bar and menu, with a number box by each slider
  • Nine script slots that each remember their place
  • Layout controls: margins, spacing, reading line, eye-line
  • Word, PDF, Google Docs, rich and plain-text scripts
  • Microphone choice with a live level meter
  • Settings saved to JSON or XML
  • A floating pad, a phone remote and a control window
  • Mirroring, hiding from screen sharing, and click-through
  • A pacing light, talking points, markers and take summaries
  • Script directives for stops, countdowns, pace and targets
  • Reading aids: focus band, colours and fonts
  • Dimmed notes to the speaker, and slide-cue highlights

Sightline Prompter

Sightline Prompter can load any markdown and/or HTML syntax and display that as a translucent overlay on the screen. In this way you can load a script and still see your presentation, video conferencing, or any other applications through the script.

Move the mouse to show the control bar, then press Open (or Ctrl+O) to load a script, or drop a file onto this window. Press F1 for the keyboard shortcuts.

Settings

Scrolling

A sync point for the edit. Before each take the screen flashes white and shows the section and take number for a second; with the beep, your microphone records it too. The take log notes when each slate went off, so every take can be lined up with the recording. Start reading after the beep.

Voice scroll sync

Say “Prompter” then a command, and stop: pause, go, slower, faster, back, next section, from the top, again, marker, resync, bigger, smaller. While steady scrolling, the microphone stays on to listen for them (on this computer only; nothing is sent anywhere).

Choose Voice as the mode on the Scrolling tab to use these.

Layout

Changes here show straight away, so you can see them on the script. Cancel doesn't undo them.

Scripts

Scripts can be Markdown, plain text, Word (.docx), rich text (.rtf) or web pages (.html).

Settings file

JSON or XML. Useful for moving your set-up to another computer.

Display

Opens the prompter full screen on that monitor, now and each time the app starts. F11 gives a normal window there. Control it from another screen with the control window (Ctrl+Shift+O).

Slide cues

Underlined words in rich-text and Word scripts are highlighted too.

Phone remote

Scan this with the phone's camera, then add the page to the home screen for next time.

Only a device with the code in the QR code can control the prompter. The first time, Windows may ask whether to allow Sightline Prompter on the network: allow it on private networks. New code disconnects any phone already connected. Turn this off when you don't need it.
